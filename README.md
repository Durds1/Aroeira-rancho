# Rancho Aroeira

Site da chácara Rancho Aroeira, na beira do lago em Três Ranchos-GO. Recebe até 10 pessoas, tem 3 quartos e fica a 3 km da cidade.

## Arquivos

- `index.html`: a página inteira (estilo e código ficam no próprio arquivo)
- `fotos/`: as fotos usadas no site

## Como alterar

- **Número do WhatsApp:** no `index.html`, procure `const WHATSAPP` e troque os dígitos (55 + DDD + número).
- **Fotos:** coloque o arquivo novo em `fotos/` e troque o nome dele no `index.html`.

O site é publicado pelo GitHub Pages a partir da branch `main`.
